# 📁 Python File Handling Project

This is a beginner-level Python project that demonstrates basic file handling operations using the `pathlib` module and exception handling.

The program is menu-driven and allows users to manage files directly from the terminal.

---

## 🚀 Features

- ✅ Create a new file
- 📖 Read an existing file
- ✏️ Update a file
  - Rename the file
  - Overwrite file content
  - Append new content
- 🗑️ Delete a file
- 📂 View all files and folders in the current directory

---

## 🛠️ Concepts Used

- Functions
- Conditional Statements
- Exception Handling (`try-except`)
- File Modes (`r`, `w`, `a`)
- `pathlib` Module
- `os` Module
- User Input Handling
